## 重要边界

- `experiments/`、`reports/`、`configs/` 是实验和机器证据，不是普通说明文档。
- 历史 manifest 中仍可能记录重构前的文档路径；它们是冻结证据，不能为了改名而重写。
- 正式 Retail SFT、DPO、GRPO 仍未完成；隔离工程实操执行包已就绪，但只有 GPU 运行与自动验收通过后才能声称完成工程实操闭环。

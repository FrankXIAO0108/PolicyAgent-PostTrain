## 1. 升级决定

## 6. 下一步放行顺序

1. 为前 8 个 `rl_train` 任务单独生成 opening 文件，不覆盖 1-task sanity 输入。
2. 建立 Qwen3-4B 的 8-task、每任务 4 候选 rollout-only 配置。
3. 开启 TRL `log_completions`，补齐无工具普通文本 completion 的可观测性。
4. 统计工具解析率、必要动作匹配率、reward 非零率、组内 reward 标准差和异常写入率。
5. 与 Qwen2.5-0.5B 的同任务结果比较。
6. 若仍大面积零奖励，先做 Retail Tool SFT warm-up；不得直接扩大 GRPO step。
7. 只有 reward-variance gate 通过后，才运行正式 GRPO。

建议第一轮门禁：

- Tool Calling 解析成功率不低于 95%；
- 至少 50% 的任务组出现非零 reward 方差；
- 必要动作匹配不再全部为 0；
- 高 reward 轨迹抽查无越权和 reward hacking；
- 原始 completion、工具轨迹与 reward breakdown 均可追溯。

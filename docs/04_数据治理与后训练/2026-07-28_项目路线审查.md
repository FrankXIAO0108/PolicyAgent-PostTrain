- 没有启动 SFT、DPO、RLHF 或 GRPO；
- 没有把 provisional 标签升级为训练 gold；

项目曾出现轻微的战术偏移：

- 2026-07-27 已经生成 label-blind 政策审阅包；

## 2026-08-02 补充审查：隔离工程实操是否偏离路线

结论：执行包本身不构成正式路线偏移，但必须同时满足以下边界：

- 只使用开发者合成数据，不读取 frozen task 或 provisional 标签；
- 输出目录、checkpoint 和指标与正式 Retail 实验分开；
- 目的限定为验证 SFT、DPO、GRPO 的训练工程能力；
- 不据此打开正式 SFT/DPO/GRPO readiness gate；
- 不把 synthetic holdout 变化表述成业务成功率提升；
- 先跑 2.43M 参数 API sanity，再跑 0.5B 主实操，控制算力成本；
- 只有三阶段 checkpoint、有限 loss、哈希和四组冻结评测全部通过自动验收，才允许
  声称“完成工程闭环实操”。

因此，正式主线仍是“独立裁决 → 正式 SFT 数据 → SFT 对比 → 条件性 DPO/GRPO”；
新增路线是求职所需的隔离 training sandbox，不替代也不伪造正式业务证据。

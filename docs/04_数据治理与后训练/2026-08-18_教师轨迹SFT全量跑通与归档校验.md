## 2. 排障链（2026-08-18 晚间，按提交记录）

1. `b229627` — Qwen3 模板无 `{% generation %}`，原生 assistant mask 不可用；改为**整段渲染差分**（每轮渲染两次定位字符 span + offset_mapping 映射 token），fail-closed 校验。
2. `0c52cf8` — transformers 5.14.1 的 `BatchEncoding` 不是 dict 子类，统一按下标访问。
3. `e1ce991` — 数据集路径改为 manifest 注册路径（原硬编码 `sft_dataset.jsonl` 是 bug）；max_length 8192 → 16384（远程实测最长 13954）。
4. `82bc120` — CUDA OOM 根因两处：
   - `evaluate_validation` 传 `labels` 触发模型内部 `float()` + `contiguous()`（14k 序列约 8GB 瞬时拷贝）；
   - 全量 logits 本身约 4GB。
   修复：不传 labels，改为手动分块 NLL（`index_select` 只取有效位置，避免整段拷贝）；验证序列截断到 `validation_max_length=8192`（保留尾部）。
5. `009b09f` — 归档校验发现 `directory_sha256` 排序跨平台不一致（WindowsPath 大小写不敏感 vs PosixPath 大小写敏感，同一目录 Linux/Windows 哈希不同）；抽出 `src/training/dirhash.py` 统一按相对 posix 字符串排序，三处 runner（`run_retail_agentic_grpo` / `run_posttrain_engineering_smoke` / `evaluate_adversarial_holdout`）改用公共实现。

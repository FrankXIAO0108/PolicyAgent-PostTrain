- Benchmark / Evaluator Audit；
- User Simulator 一致性检查；
- Reward Label Noise 分析；
- Latest Intent Tracking；
- Final Authorized Intent 验证；
- Confirmation Mechanism 评估。

经过人工裁决后，它甚至可能成为一个“正确遵循用户最终意图”的正向轨迹候选。


12. 候选改进方案：

Benchmark / 数据侧：

1. 在任务定义中明确指定目标订单实体，避免“旧订单”“那个订单”等模糊指代。

2. 对 User Simulator 增加一致性约束，防止其生成与 Golden Actions 冲突的用户意图。

3. 增加自动一致性检查：

Task Instruction
→ User Simulator Intent
→ Golden Actions
→ NL Assertions

四者必须一致。

4. 对动态用户意图任务，不应完全依赖固定 Static Golden。

可以考虑引入：

Final Authorized Intent
→ Expected Execution

这种基于最终授权意图的动态评测机制。

5. 将 Task 59 暂时标记为：

BENCHMARK_SUSPECT
USER_SIMULATOR_GOLD_MISMATCH

在人工裁决前不进入普通失败训练集。


项目实验侧：

原始 Trial-1 结果不 retroactively 修改。

仍然保留：

Raw Baseline:

同时额外记录：

Task 59:
BENCHMARK_SUSPECT
